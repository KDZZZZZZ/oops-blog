# Oops 开源博客 UI/UX PRD

## 1. 产品定位

一个开源、内容优先的个人博客，公开署名统一使用 **Oops**。站点记录 AI 编译器、Agent 工程与模型推理优化，视觉参考 innei.in 的留白、阅读节奏与低幅动效，但不复制其品牌、文案或私有组件。

## 2. 信息架构

博客采用独立页面，而不是把所有内容堆在同一个长页。

| 页面 | 文件 | 职责 |
| --- | --- | --- |
| 首页 | `index.html` | 个人定位、最新文稿、近期随笔与短状态；只做入口 |
| 文稿 | `posts.html` | 按时间、按类别和统计概览三种浏览方式 |
| 随笔 | `essays.html` | 工程现场、实验片段与未长成文章的短记 |
| 项目档案 | `projects.html` | 保留的深层内容页，不进入顶部主导航 |
| 关于 | `about.html` | 保留的深层内容页，承担开源与许可说明 |
| 文章详情 | `article-lowering.html` | 独立阅读页，包含目录、正文与上一篇/下一篇导航 |

顶部导航固定为“首页 / 文稿 / 随笔 / 更多”。前三项使用真实页面链接；“更多”只展示禁用状态，不包含链接或点击行为。首页不重复展开完整文稿、随笔正文或开源许可清单。

## 3. 视觉系统

- 视觉 token 以`docs/brand-spec.md` 为准。
- 暖白纸面、三档中性文字、单一梅色强调；强调色每屏最多两处。
- 中文衬线承担标题和文章正文，无衬线承担界面与说明，等宽字体仅用于编号和元信息。
- 结构依赖留白与 1px 分隔线，不使用卡片墙、硬阴影或大面积渐变。
- 正文宽度控制在 `68ch`，页面最大宽度 `1180px`。

## 4. 首页职责

首页采用参考站的页面节奏，但使用 Oops 的真实内容与原创组件：

1. 全视口首屏：头像、两行自述、工程方向；首屏下缘展示真实内容状态和联系入口。
2. 内容主体：约 2:1 双栏布局，左侧最多三篇近期文稿，右侧承载近期随笔与当前状态。
3. 写作轨迹：以真实内容的“已发布 / 整理中 / 短记”状态构成横向轨迹，不虚构发布日期或产量。
4. 联系与页脚：提供邮件、开源说明和真实页面链接。

首页不放筛选器、完整文稿时间线、长篇开源说明或全部研究方向，也不复制 innei 的文案、统计与品牌资产。

## 5. 动效合同

- 页面进入：`translateY(12px)` + 淡入，70ms 交错，缓动 `cubic-bezier(.22, 1, .36, 1)`。
- 首屏滚动：标题最多上移 28px 并轻微淡出，不遮挡下一节。
- 列表悬停：横向位移不超过 4px；不使用弹跳、缩放或持续循环动画。
- 页面跳转使用浏览器原生导航，避免用单页锚点伪装多页面。
- `prefers-reduced-motion` 下取消位移和交错延迟。

## 6. 共享组件

- `SiteHeader`：真实页面导航、当前页状态、搜索、主题切换、移动端抽屉。
- `EntryRow`：文章与项目索引的无卡片列表行。
- `SearchDialog`：跨页面搜索，结果直接跳转到对应页面。
- `ThemeToggle`：跟随系统并持久化到 `oops-theme`。
- `ArticleShell`：标题、元信息、窄正文、目录、文末导航。

## 7. 响应式策略

- `360–599px`：单列，44px 触控目标，移动导航抽屉，文章目录回到正文上方。
- `600–899px`：单列加宽，列表元信息与正文保持两段式层级。
- `900–1279px`：启用双列文章页和项目元信息列。
- `1280px+`：只增加留白，不连续放大字号或正文行宽。
- 在 360、390、430、600、768、1024、1366、1440、1920px 下禁止水平滚动。

## 8. 原创与许可边界

- 可参考并复用 Yohaku `design-system/` 的 MIT 设计契约。
- 不复制完整 Yohaku 应用、innei 的品牌识别、导航命名、文章分类或私有动效组件。
- 不以 Shiro 或 Mix Space 应用层作为代码底座，避免默认引入 AGPL 与附加条款。
- 页面结构、CSS 与 JavaScript 均独立实现，并在 `THIRD_PARTY_NOTICES.md` 中保留来源说明。

## 9. 验收标准

- “首页 / 文稿 / 随笔”均指向独立 HTML 文件；“更多”保持不可点击。
- 文稿页三种视图可通过鼠标与方向键切换，统计只使用页面中真实存在的内容样本。
- 首页首屏之后只保留精选入口，不展开完整档案。
- 主题、搜索、移动导航可用，键盘与 Escape 操作完整。
- 所有用户可见署名均为 Oops，不出现实名或可识别缩写。
- 页面无虚构指标、阅读量、发布日期或外部占位图。
- 站点在无 JavaScript 时仍可阅读和导航。
